# 📖 About This Repository

This repository was created as a **learning project** to explore and understand **Role-Based Access Control (RBAC)** in Laravel using the **Spatie Laravel Permission** package.

The primary goal was to gain hands-on experience implementing roles, permissions, middleware protection, and authorization in a Laravel 11 application.

This is a practice project intended for learning and experimentation rather than production use.

---

# 🎯 Learning Objectives

* Install and configure Spatie Laravel Permission
* Create Roles
* Create Permissions
* Assign Roles to Users
* Assign Permissions to Roles
* Assign Direct Permissions to Users
* Protect Routes with Middleware
* Authorize Users
* Implement Role-Based Access Control (RBAC)
* Follow Laravel authorization best practices

# 🚀 Installation

```bash
git clone https://github.com/yourusername/spatie-laravel-roles-permissions.git
```

```bash
cd spatie-laravel-roles-permissions
```

```bash
composer install
```

```bash
cp .env.example .env
```

```bash
php artisan key:generate
```

Update your database credentials inside the `.env` file.

```bash
php artisan migrate
```

```bash
php artisan db:seed
```

```bash
php artisan serve
```
